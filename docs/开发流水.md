### 1. 增加任务闹钟提醒功能
**目标**：允许用户为任务设置一个定时提醒
**分析与过程**：
- **数据库拓展**: 为 `records` 表新增了 `notified_at` （文本类型存储 RFC3339）与 `scheduled_for`。支持旧数据的降级迁移。
- **UI 更新**: 在 `TaskPanel` 的每个待办任务后添加 ⏰ 图标。点击后内联显示一个带浅黄色背景的快速输入框，利用 `chrono-english` 自然语言解析（支持 `+1m` 等时间偏移与 `15:30` 等具体时间）。
- **后台通知引擎**: 由于 `GPUI` 未启用外部执行层且底层业务同步化，我们在 `StoreRuntime` 中通过 `std::thread::spawn` 拉起了一个休眠 10 秒钟轮询的后台原生操作系统线程，不断从 SQLite 吸取到期未通知（`notified_at IS NULL`）的计划任务进行系统通知下发。

### 2. macOS 通知权限兼容 (打包为 .app)
**目标**：解决 `cargo run` 直接运行由于没有有效 Bundle ID 时 macOS 静默拦截桌面通知。
**分析与过程**：
- **移除过重的通知库**: 使用了 `osascript` 直接调用系统方法 `display notification` 以逃逸对于证书验证的部分严格限制（并且跨平台 `notify-rust` 同样被拦截）。
- **打包为 .app Bundle 机制**: 编写了一个简易脚本 `build_mac_app.sh` 将当前编译结果包装出标准的 `Beitang.app/Contents/MacOS/beitang` 与必要的 `Info.plist`，以此来激活 macOS 的通知权限提示和横幅显示。

### 3. 右键菜单深度视觉精修
**目标**：完全复刻滴答清单样式，提升 UI 质感。
**分析与过程**：
- **自研 ContextMenu 渲染**: 由于组件库自带的 `PopupMenu` 在浅色模式下存在阴影过重（“脏”）、图标丢失且布局僵硬等问题，改为在 `TaskPanel` 中基于 `deferred` 和 `anchored` 叠加层从零实现。
- **视觉复刻**: 
    - 顶部加入“日期”快捷操作行，支持“今天/明天/下周/选择”四个图标按钮。
    - 弃用 Emoji，改用 `IconName` 矢量图标并显式指定 `rgb(0x666666)` 颜色增强细节。
    - 自定义 `shadow_md` 阴影和 `rgb(0xe0e0e0)` 边框，实现清爽、高级的悬浮感。
- **交互逻辑**: 整合 `on_mouse_down_out` 实现点击外部自动关闭，并优化了 Action 分发逻辑。

### 4. 任务标题内联编辑 (Inline Editing)
**目标**：允许用户点击标题直接在列表内重命名。
**分析与过程**：
- **状态切换**: 在 `render_task` 中根据 `editing_task_id` 动态切换“文本标签”与“输入组件”。
- **交互增强**: 
    - 点击标题即可触发 `start_edit`。
    - 在内联输入框中增加了 `KeyDownEvent` 监听，实现 `Enter` 快速保存修改，`Esc` 放弃更动并退出编辑态。
- **稳定性**: 解决了 GPUI 对于动态列表项中交互元素 ID 的类型约束问题，确保了输入框的自动聚焦效果。
