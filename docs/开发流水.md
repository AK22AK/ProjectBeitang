# 开发流水记录

## 2026-03-09

### 1. 修复 Cmd+N/M 崩溃问题
- **发现问题**：在使用 Cmd+N/M 呼出浮动输入窗口时，`gpui_component::input::Input` 组件试图读取其所在的全局 `Root` context 获取主题等配置，由于外层未被 `Root` 包裹，导致 `unwrap` panic 崩溃。
- **解决方案**：修改 `src/main.rs` 里的开窗逻辑，将单纯加载 `QuickAddWindow` 改为了外部包裹使用 `gpui_component::Root::new(view, window, cx).bg(...)` 进行渲染。

### 2. 修复快捷键优先级（!! / ！！）解析失效 Bug
- **发现问题**：通过快速输入小窗和主应用面板输入 `!! 高优先级` 或 `！普通优先级任务` 时，带有中文全角感叹号（`！`，`！！`）的前缀无法被代码识别，导致任务最终以“普通/低优先级”写入数据库。
- **解决方案**：在 `src/ui/floating_window.rs` 的 `parse_quick_input` 和 `src/ui/task_panel.rs` 的 `parse_input_static` 两个解析函数中，引入 `strip_prefix` 方法，同时匹配半角和全角的感叹号 (`!!`, `！！`, `!`, `！`) 进行识别和截断。
- **测试通过**：运行 `cargo test` 顺利通过全量测试集，保证了文本解析与 SQLite 持久化入库逻辑的完善。
