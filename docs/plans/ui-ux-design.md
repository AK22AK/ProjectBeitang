# Robinne - UI/UX 设计文档

**文档日期**: 2026-03-22  
**版本**: 1.0  
**设计风格**: 极简、原生感、性能优先

---

## 一、设计原则

### 1.1 核心准则

- **简洁至上**: 无多余元素，每个像素都有目的
- **性能优先**: 即时响应，无加载等待
- **颜色点缀**: 只用小块颜色点缀，避免大块色块
- **原生体验**: 参考 Raycast、滴答清单的克制设计
- **不被打扰**: 用完即走，无侵入式引导

### 1.2 视觉规范

**色彩**:
- 主背景: 系统默认（深色/浅色模式自适应）
- 文字: 中性灰度，层次分明
- 点缀色: 优先级颜色（红/黄/绿）仅用于小标记

**字体**:
- 使用系统默认字体，保持一致性

**图标**:
- 简洁线条图标，统一风格
- 时间节点用不同图标区分类型

## 二、核心面板设计

### 2.1 快速输入面板（全局浮动）

**呼出方式**: 全局快捷键 `Cmd+Shift+Space`

**视觉设计**:
```
┌─────────────────────────────────────┐
│                                     │
│   输入内容...                        │  ← 自动聚焦
│                                     │
├─────────────────────────────────────┤
│  [任务]  [记录]                      │  ← Tab 切换，记录默认
├─────────────────────────────────────┤
│  ⚡ Enter 保存并关闭                  │
│  ⚡ Cmd+Enter 打开主界面              │
│                                     │
└─────────────────────────────────────┘
```

**特点**:
- 圆角矩形，无边框，半透明背景（Raycast 风格）
- 居中显示，尺寸紧凑（约 600x400px）
- 输入框占主导，其他元素弱化

**交互细节**:
- 默认模式: **记录模式**（纯文本输入）
- Tab 切换到任务模式:
  - 支持 `!!` `!` 语法标记优先级
  - 输入框下方显示优先级提示条
- Enter: 保存并关闭，返回之前界面
- Cmd+Enter: 保存并打开主界面
- Esc: 关闭面板

### 2.2 首页看板（主界面）

**入口**: 应用启动默认，快捷键 `Cmd+1`

**布局**（响应式）:
```
┌─────────────────────────────────────────────────────┐
│ 🔍                      [看板] [时间线] [任务] [AI]  │
├─────────────────────────────────────────────────────┤
│                                                     │
│  ┌──────────────── 进行中 ─────────────────┐       │  ← 最醒目
│  │                                         │       │
│  │  ▶ 修复生产bug               2小时30分  │       │
│  │     开始于 11:00                        │       │
│  │                                         │       │
│  └─────────────────────────────────────────┘       │
│                                                     │
│  ┌──────────────── 待办 ──────────────────┐       │
│  │                                         │       │
│  │  !! Q3报告                 DDL今天     │       │
│  │  !  回复客户邮件                        │       │
│  │  !! 修复生产bug            [进行中]     │       │
│  │  !  更新文档                            │       │
│  │       ── 还有 3 个 ──                  │       │
│  │                                         │       │
│  └─────────────────────────────────────────┘       │
│                                                     │
│  ┌──────────────── 回顾 ──────────────────┐       │
│  │                                         │       │
│  │  ☑ 提交代码审查              昨天 17:30 │       │
│  │  📝 需求评审会议             昨天 15:00 │       │
│  │  💡 想到新方案...            前天 10:00 │       │
│  │                                         │       │
│  └─────────────────────────────────────────┘       │
│                                                     │
│  常用: #工作 #个人      统计 →                      │
│                                                     │
└─────────────────────────────────────────────────────┘
```

**区域说明**:

| 区域 | 内容 | 排序/筛选 |
|------|------|-----------|
| **进行中** | 当前标记为"进行中"的任务 | 按开始时间倒序，显示已进行时长 |
| **待办** | 所有未完成的任务 | 按四象限规则排序，显示前 N 个 |
| **回顾** | 最近的历史记录 | 按时间倒序，显示最近 N 条 |

**响应式规则**:
- 窗口偏横向: 子区域纵向排列
- 窗口偏纵向: 子区域横向排列（类似手机）

**交互细节**:
- 点击任务直接编辑
- 点击"还有 N 个"跳转到任务面板
- 常用标签/人物点击后跳转到时间线并自动筛选

### 2.3 时间线面板（历史视图）

**入口**: 快捷键 `Cmd+2`

**视觉设计**（真正的"一条线"）:
```
时间线面板:

[全部] [工作] [个人] [代码重构] [+固定]     🔍 搜索   ← 顶部筛选胶囊

      14:30 ────●──── 完成代码审查
                │
      11:00 ────●──── 开始修复生产bug
                │          [进行中]
                │
      10:30 ────●──── 💡 想到可以用工厂模式
                │
      昨天 ─────●──── ☑ 完成Q3报告
                │
      前天 ─────●──── ! 创建重构任务
                │
                         ↓ 滚动加载更多
```

**设计要点**:
- 时间线: 一条细灰色竖线，贯穿始终
- 位置: 偏左（约 80px 处），左边显示时间戳，右边显示内容
- 节点标记:
  - `●` 普通记录/想法
  - `◎` 任务创建
  - `☑` 任务完成（绿色点缀）
  - `▶` 任务进行中（蓝色点缀）
  - `✕` 任务取消（灰色/红色点缀）

**顶部筛选胶囊**:
- 最左侧: "全部"
- 右侧: 用户固定的标签（可编辑）
- 最右侧: "+固定" 按钮添加新标签
- 点击胶囊切换筛选，多选为 AND 关系

**交互细节**:
- 点击条目展开详情侧边栏
- 虚拟滚动，万条记录不卡顿
- 滚动到底部自动加载更多

### 2.4 任务管理面板

**入口**: 快捷键 `Cmd+3`

**视图切换**:
```
[列表视图 ▼]  [高] [中] [低] [全部]  ← 视图切换 + 优先级筛选
```

**四象限矩阵视图**:
```
┌─────────────┬─────────────┐
│   重要且紧急  │   重要不紧急  │
│  ─────────── │  ─────────── │
│  !! Q3报告   │  ! 学Rust    │
│  !! 修bug    │              │
├─────────────┼─────────────┤
│   不重要紧急  │  不重要不紧急 │
│  ─────────── │  ─────────── │
│  回邮件      │  整理桌面    │
│              │              │
└─────────────┴─────────────┘
```

**列表视图**:
- 按四象限规则排序的单列表
- 显示完整任务信息（内容、DDL、标签）

**交互细节**:
- 任务自动归类到象限（根据优先级+DDL紧迫度）
- 点击任务展开详情侧边栏
- 侧边栏可编辑：状态、优先级、DDL、标签、内容
- 不拖拽调整（首版本），通过编辑属性改变位置

## 三、图标系统

### 3.1 时间节点图标

| 图标 | 含义 | 颜色 |
|------|------|------|
| `●` | 普通记录/想法 | 灰色 |
| `◎` | 任务创建 | 蓝色 |
| `▶` | 任务进行中 | 蓝色（轻微脉动或静态）|
| `☑` | 任务完成 | 绿色 |
| `✕` | 任务取消 | 红色/灰色 |

### 3.2 类型图标

| 图标 | 类型 |
|------|------|
| `📋` | 任务 |
| `📝` | 记录 |
| `💡` | 想法 |

## 四、颜色使用规范

### 4.1 优先级颜色（点缀）

| 优先级 | 颜色 | 使用位置 |
|--------|------|---------|
| High (`!!`) | 红色 | 左侧小标记、文字颜色 |
| Medium (`!`) | 黄色/橙色 | 左侧小标记、文字颜色 |
| Low | 绿色/灰色 | 左侧小标记、文字颜色 |

### 4.2 状态颜色

| 状态 | 颜色 | 使用位置 |
|------|------|---------|
| 进行中 | 蓝色 | 节点图标、标签 |
| 已完成 | 绿色 | 节点图标 |
| 已取消 | 灰色/红色 | 节点图标 |

### 4.3 原则

- **只用小块颜色点缀**，不用大块背景色
- 文字主体保持中性色（黑/白/灰）
- 深色/浅色模式自适应

## 五、交互反馈

### 5.1 操作反馈

| 操作 | 反馈 |
|------|------|
| 保存成功 | 无提示（瞬时完成，无感知）|
| 删除确认 | 无确认（可撤销或温和提示）|
| 加载更多 | 底部显示"加载中..."，完成后自然融入 |
| 搜索无结果 | 居中提示"未找到相关内容" |

### 5.2 过渡动画

- **原则**: 尽量不用动画，或极短（<150ms）
- 面板切换: 瞬间切换，无淡入淡出
- 列表加载: 直接出现，无渐变

## 六、响应式设计

### 6.1 窗口尺寸适配

| 尺寸类型 | 布局调整 |
|---------|---------|
| 宽屏 (>1200px) | 首页三区域横向排列，时间线宽敞 |
| 中屏 (800-1200px) | 首页三区域纵向排列 |
| 窄屏 (<800px) | 侧边栏收起，简化导航 |

### 6.2 首页区域排列

- **窗口偏横向**（宽屏）: 三区域纵向堆叠
- **窗口偏纵向**（窄屏）: 三区域横向并排或简化
