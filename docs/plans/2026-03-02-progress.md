## 已知问题 ⚠️

### 1. 感叹号语法未生效
**现象**: 输入 `!! 高优先级任务` 或 `! 普通优先级任务`，优先级识别不正确

**可能原因**:
- `parse_input` 方法逻辑问题
- 或者数据库中的 priority 列存储格式与读取格式不匹配

**代码位置**: `src/ui/task_panel.rs:89-98`

```rust
fn parse_input(&self, input: &str) -> (String, Priority) {
    let trimmed = input.trim();
    if trimmed.starts_with("!! ") {
        (trimmed[3..].to_string(), Priority::High)
    } else if trimmed.starts_with("! ") {
        (trimmed[2..].to_string(), Priority::Medium)
    } else {
        (trimmed.to_string(), Priority::Low)
    }
}
```

### 2. 数据库表结构不匹配
当前数据库表是之前版本创建的，列顺序和类型可能与代码期望的不一致：
- `priority` 列在数据库中是 TEXT 类型
- 代码中解析为整数后再映射到 Priority 枚举

**建议**: 删除旧数据库文件让应用重新创建：
```bash
rm ~/Library/Application\ Support/robinne/data.db
```

### 数据库列类型处理
由于数据库中 priority 是 TEXT 类型，读取时需要先读字符串再解析：

```rust
let priority_str: Option<String> = row.get(2)?;
priority: priority_str.and_then(|s| s.parse::<i64>().ok()).map(|p| match p {
    0 => Priority::High,
    1 => Priority::Medium,
    _ => Priority::Low,
}),
```
