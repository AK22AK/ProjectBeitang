## 二、v0.1 MVP 详细规划

### 2.1 目标

用户可以：
1. 用快捷键快速记录任务和想法
2. 在首页看板看到进行中/待办/回顾
3. 在时间线查看历史
4. 搜索内容

### 2.2 功能清单

#### P0 - 必须有

**数据层**:
- [ ] SQLite 数据库初始化
- [ ] records 表 CRUD
- [ ] FTS5 全文搜索表
- [ ] tags/persons 基础关联

**快速输入面板**:
- [ ] 全局快捷键呼出
- [ ] 任务/记录模式切换
- [ ] `!!`/`!` 优先级语法
- [ ] Enter 保存，Cmd+Enter 跳转主界面

**首页看板**:
- [ ] 进行中区域（显示标记为进行中的任务）
- [ ] 待办区域（四象限排序展示）
- [ ] 回顾区域（最近记录）
- [ ] 点击跳转详情

**时间线面板**:
- [ ] 竖向时间线视图
- [ ] 节点图标区分类型
- [ ] 虚拟滚动
- [ ] 点击展开详情

**任务管理面板**:
- [ ] 列表视图
- [ ] 四象限矩阵视图
- [ ] 状态切换（Todo → InProgress → Done）
- [ ] 优先级/DDL 编辑

**搜索**:
- [ ] 顶部搜索栏
- [ ] FTS5 全文搜索
- [ ] 结果列表

#### P1 - 应该有

- [ ] 标签筛选（顶部胶囊）
- [ ] 人物关联
- [ ] 基础设置面板（快捷键配置）
- [ ] 数据导入导出（JSON/SQLite）

#### P2 - 可以有

- [ ] 附件图片支持
- [ ] 图片压缩
- [ ] 统计面板（简单数字）

## 六、未来规划（不承诺时间）

### 6.1 可能的功能

| 功能 | 说明 | 优先级 |
|------|------|--------|
| iCloud 同步 | 自动跨设备同步 | 中 |
| WebDAV 同步 | 支持自定义网盘 | 中 |
| 本地大模型 | 离线 AI 总结 | 低 |
| 移动端 | iOS/Android 版本 | 低 |
| 浏览器插件 | 网页内容快速记录 | 低 |
| API 接口 | 第三方集成 | 低 |

### 6.2 已否决的功能

| 功能 | 否决原因 |
|------|---------|
| 云端服务 | 违背本地优先原则 |
| 多用户 | 个人工具定位 |
| 复杂提醒通知 | 违背"不打扰"原则 |
| 子任务依赖 | 过于复杂，标签可替代 |
| 移动端 | 技术栈限制（GPUI）|

## 八、决策记录

### 8.1 已做出的决策

| 日期 | 决策 | 理由 |
|------|------|------|
| 2026-03-22 | 时间线作为主视图 | 最直观展示"做过什么" |
| 2026-03-22 | FTS5 首版本就用 | 保证长期使用体验 |
| 2026-03-22 | 标签筛选代替专题看板 | 保持简洁，功能足够 |
| 2026-03-22 | 不进行中的任务不重复显示 | 避免信息冗余 |
| 2026-03-22 | 截图保持 PNG，照片转 JPEG | 截图本身不大 |
