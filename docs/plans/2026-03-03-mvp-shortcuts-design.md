# MVP 快捷键与窗口系统设计

## 设计决策

**方案选择：B（编辑浮动 + 查看主窗口）**

理由：
- 编辑操作追求"用完即走"，浮动窗口最合适
- 查看操作需要完整信息展示，主窗口更合适
- 查看后可在主窗口继续操作，流程自然

---

## 快捷键设计

### 默认快捷键

| 快捷键 | 功能 | 窗口类型 | 行为 |
|--------|------|----------|------|
| **Cmd+N** | 快速添加任务 | 浮动窗口 | 输入框聚焦，回车保存关闭 |
| **Cmd+M** | 快速添加笔记 | 浮动窗口 | 输入框聚焦，回车保存关闭 |
| **Cmd+1** | 查看任务列表 | 主窗口 | 激活主窗口 → 切换到任务面板 |
| **Cmd+2** | 查看笔记列表 | 主窗口 | 激活主窗口 → 切换到笔记面板 |
| **Cmd+0** | 打开主窗口 | 主窗口 | 激活主窗口，保持当前面板 |

### 快捷键行为规则

**浮动窗口（Cmd+N / Cmd+M）：**
- 呼出：显示浮动窗口，输入框自动聚焦
- 输入内容，回车提交
- 提交后：保存数据，关闭窗口，显示成功提示（可选）
- 取消：按 Esc 或再按快捷键关闭窗口

**主窗口（Cmd+1 / Cmd+2 / Cmd+0）：**
- 呼出：激活/显示主窗口，切换到对应面板
- 关闭：按 Esc 或再按相同快捷键关闭窗口
- 切换：不同快捷键之间切换面板，不关闭窗口

## 窗口设计

### 浮动窗口规格

**快速添加任务窗口：**
```
尺寸：400px × 120px
位置：屏幕居中（或鼠标附近）
样式：圆角 12px，无边框，阴影
内容：
  - 输入框（占满宽度）
  - 优先级选择（!!高 !中 低）
  - 提示文字：Enter 保存，Esc 取消
```

**快速添加笔记窗口：**
```
尺寸：500px × 200px
位置：屏幕居中
样式：同上
内容：
  - 标题输入框（单行）
  - 内容输入框（多行）
  - 提示文字
```

### 主窗口行为

- 支持标准窗口操作（最小化、关闭）
- 关闭按钮：隐藏窗口（不退出应用）
- 应用保持后台运行，快捷键可随时呼出

## 技术要点

### 全局快捷键注册

使用 `global-hotkey` crate 或其他平台库注册系统级快捷键：
- 应用启动时注册
- 应用退出时注销
- 快捷键冲突检测（提示用户）

### 窗口管理

- 浮动窗口：临时窗口，不保存状态
- 主窗口：单例，保存面板状态
- 窗口间共享 Store 数据

### 配置持久化

快捷键配置存储在 SQLite 或配置文件中：
```json
{
  "shortcuts": {
    "quick_add_task": "Cmd+N",
    "quick_add_note": "Cmd+M",
    "view_tasks": "Cmd+1",
    "view_notes": "Cmd+2",
    "open_main": "Cmd+0"
  }
}
```
