## 一、项目定位

### 1.1 核心定义

**"工作中的闪念大脑"** —— 一个超快的个人工作事务管理工具。

### 1.2 核心价值主张

用户只需要关注两个核心信息：
- **我要做什么**（未来/待办）
- **我做过了什么**（过去/回顾）

一切设计围绕这两个核心展开。

### 1.3 三大设计原则

| 原则 | 目标 | 说明 |
|------|------|------|
| **0.5秒呼出** | 任何情况下 0.5 秒内呼出界面 | 快捷键触发，无延迟感知 |
| **3秒完成记录** | 记录一个事务不超过 3 秒 | 简洁输入，无干扰流程 |
| **不打扰** | 用完即走，不抢占注意力 | 无弹窗、无提醒、无侵入式引导 |

### 1.4 体验对标

- **Raycast**: 隐藏待命，快捷键呼出，完成即走的交互模式
- **滴答清单/Todoist**: 任务管理的简洁性、四象限展示

## 二、用户场景与核心输入行为

### 2.1 用户核心问题

| 用户问题 | 信息来源 | 数据形式 |
|---------|---------|---------|
| 我要做什么？ | 之前安排的任务 | 未完成的 Task |
| 我做过了什么？ | ① 已完成的 Task + ② 随手记录 | Completed Task + Event/Idea |
| 我正在做什么？ | 当前标记为"进行中"的任务 | InProgress Task |

### 2.2 支持的输入行为

**已实现确认的场景**（MVP 必须支持）：

1. **创建任务**: 输入 `!!`/`!` 标记优先级，生成未来任务
2. **添加记录**: 直接输入内容，生成过去记录
3. **完成任务**: 勾选/标记完成 + 可选时间，任务移动到过去
4. **取消任务**: 标记为取消 + 原因，负向关闭
5. **编辑**: 修改任何已有内容
6. **补记**: 选择过去时间点 + 输入
7. **设置 DDL/提醒**: 给任务附加时间属性
8. **延后提醒**: 一键推迟提醒时间（不修改 DDL）
9. **拆分任务**: 一个任务拆成两个（后续优化）
10. **标签/人物关联**: 输入 `#标签` `@人物` 做关联

**暂不支持的复杂场景**（后续版本考虑）：

- 批量操作后的统一备注
- 智能语义识别输入内容类型
- 自动提示高频标签创建专题看板

## 三、功能模块

### 3.1 核心面板清单

| 面板 | 类型 | 核心功能 | MVP优先级 |
|------|------|---------|-----------|
| **快速输入** | 浮动面板 | 全局快捷键呼出，快速记录任务/想法 | P0 |
| **首页看板** | 主界面 | 进行中 + 待办 + 回顾 + 快捷入口 | P0 |
| **时间线** | 独立面板 | 完整历史视图，支持标签筛选 | P0 |
| **任务管理** | 独立面板 | 四象限矩阵 + 列表视图 | P0 |
| **搜索/筛选** | 视图 | 全局搜索 + 标签/人物筛选结果 | P0 |
| **AI 总结** | 独立面板 | 选时间段生成工作总结 | P1 |
| **统计** | 独立面板 | 数量统计、完成率等 | P2 |
| **设置** | 抽屉/面板 | 快捷键、AI配置、默认行为 | P1 |

### 3.2 数据类型定义

三种统一的数据类型：

| 类型 | 特点 | 适用场景 |
|------|------|---------|
| **Task** | 有生命周期、优先级、DDL | 计划要做的事情 |
| **Event** | 纯内容，表示已发生 | 记录已经做过的事 |
| **Idea** | 纯内容，表示灵感 | 随时想到的点子 |

**重要设计决策**: Task 和记录共用底层数据结构，Task 是"记录的超级"，只是多了状态、优先级、时间等字段。

## 四、交互设计原则

### 4.1 核心交互准则

1. **操作路径最短**: 减少点击，快捷键覆盖所有高频操作
2. **即时反馈**: 本地存储，保存<50ms，无感知延迟
3. **无花哨动画**: 过渡干脆，不分散注意力
4. **心流保护**: 快速输入用完即走，不询问、不确认
5. **性能优先**: 虚拟滚动、增量加载、即时响应

### 4.2 快捷键设计

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| `Cmd+Shift+Space` | 呼出快速输入 | 全局可用 |
| `Esc` | 关闭任何浮动面板 | 统一退出 |
| `Cmd+1` | 首页看板 | 主界面 |
| `Cmd+2` | 时间线 | 历史视图 |
| `Cmd+3` | 任务管理 | 四象限/列表 |
| `Cmd+4` | AI 总结 | 智能分析 |
| `Cmd+K` | 聚焦搜索栏 | 全局搜索 |
| `Cmd+,` | 设置 | 配置面板 |

## 六、设计决策记录

### 6.1 已确认的关键决策

| 决策点 | 决策结果 | 理由 |
|--------|---------|------|
| 时间线作为主视图 | ✅ 是 | 最直观展示"做过什么" |
| 进行中是否重点 | ❌ 否 | 可选状态，非核心 |
| 快速输入默认模式 | 记录模式 | 随时记比计划任务更常用 |
| 四象限展示形式 | 列表排序 | 不用坐标轴 UI，保持简洁 |
| 专题追踪 | 标签筛选 | 不单独看板，用顶部胶囊筛选 |
| 进行中在首页位置 | 最顶部 | 醒目但简洁 |
| 进行中在待办显示 | ❌ 不显示 | 避免重复，首页分开即可 |
| 标签系统 | 独立表 | 支持快速列表展示 |
| FTS5 搜索 | ✅ 首版本 | 保证长期使用体验 |
| 图片压缩策略 | 截图保持 PNG，照片转 JPEG+1080px | 截图本身不大，无需压缩 |

### 6.2 待后续版本决策

- 混合输入模式（符号语法区分任务/记录）
- 专题看板（高频标签自动聚合）
- 本地大模型集成方案
- 同步策略（iCloud/WebDAV）

## 七、性能目标

| 指标 | 目标 | 说明 |
|------|------|------|
| 冷启动 | < 500ms | 应用启动到可用 |
| 快捷键到窗口显示 | < 100ms | 呼出快速输入 |
| 记录保存 | < 50ms | 感知不到延迟 |
| 搜索响应 | < 100ms | 1万条数据 |
| 时间线滚动 | 60fps | 虚拟滚动，无卡顿 |
