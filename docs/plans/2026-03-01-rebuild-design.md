# Robinne 重建设计文档

## 一、产品定义

**Robinne** —— 工作中的闪念大脑

核心价值：超快记录工作事务（任务、想法、事件），方便追溯、搜索、AI 总结。

---

## 二、技术栈

| 组件 | 选择 | 理由 |
|------|------|------|
| UI 框架 | GPUI + gpui-component | 原生 GPU 渲染，无 webview 开销，启动快 |
| 架构 | 异步通道 | UI 与数据库解耦，支持批量写入 |
| 持久化 | SQLite (rusqlite) | 全文本搜索、索引、任意数据量 |
| 配置 | JSON 文件 | 用户设置、快捷键映射 |

---

## 三、核心交互

### 全局快捷键（可自定义）

| 默认 | 功能 |
|------|------|
| Cmd+1 | 任务面板 |
| Cmd+2 | 记录面板 |
| Cmd+3 | 时间线面板 |
| Cmd+4 | AI 面板 |
| Cmd+K | 搜索（顶部栏激活） |
| Cmd+, | 设置（抽屉式侧边面板） |

### 界面布局

```
┌─────────────────────────────────┐
│ 🔍 搜索栏（全局，按 Tab 默认筛选）  │
├─────┬───────────────────────────┤
│ 📋  │                           │
│ 📝  │     内容区                │
│ ⏰  │  （任务/记录/时间线/AI）   │
│ 🤖  │                           │
├─────┤                           │
│ ⚙️  │                           │
└─────┴───────────────────────────┘
```

- **侧边栏**：图标入口，点击切换面板
- **搜索栏**：顶部常驻，按当前面板类型默认筛选
- **内容区**：展示当前面板内容
- **设置**：抽屉式侧边面板，呼出时不离开当前视图

## 四、数据模型

### Record 基础结构

```rust
enum RecordType {
    Task,   // 任务（有优先级、完成状态）
    Idea,   // 想法（纯内容）
    Event,  // 事件（已发生的事情）
}

enum Priority {
    High,   // !!
    Medium, // !
    Low,
}

struct Record {
    id: UUID,
    content: String,
    created_at: DateTime,
    record_type: RecordType,

    // Task 专属字段
    priority: Option<Priority>,
    started_at: Option<DateTime>,
    completed_at: Option<DateTime>,

    // 关联（MVP 预留，后期实现双向关联 UI）
    source_record_id: Option<UUID>,
}
```

### 快速输入语法

在任意输入框支持语法快捷创建：

| 语法 | 类型 | 优先级 |
|------|------|--------|
| `!! 内容` | Task | High |
| `! 内容` | Task | Medium |
| `内容`（无前缀）| Idea/Event | 无 |

用户可在创建后手动修改类型。

## 五、面板定义

### 1. 任务面板

- 显示所有未完成的 Task
- 按优先级分组（High → Low）
- 支持勾选完成、编辑、删除
- 显示开始时间和预计完成时间

### 2. 记录面板

- 显示所有 Idea 和 Event
- 按时间倒序
- 支持编辑内容
- 支持将 Idea 转为 Task（创建新 Task，保留原 Idea）

### 3. 时间线面板

- 混合显示所有 Record 类型
- 按日期分组（今天 / 昨天 / 更早）
- Task 显示 checkbox 和完成状态
- 显示 Task 的开始时间和完成时间

### 4. AI 面板

- 抽屉式或可固定为独立面板
- 输入时间段，AI 总结该期间的工作
- 支持提问（如"我这周做了什么？"）

---

## 六、搜索功能

- 搜索栏位于顶部，任意面板可用
- 默认按当前面板类型筛选（任务视图 → 搜任务）
- 支持过滤器语法（如 `type:task priority:high`）
- 实时搜索，结果在当前内容区展示

---

## 七、MVP 边界

### 包含
- 任务、想法、事件三种类型
- 基础 CRUD 操作
- 时间线视图
- 全局搜索
- AI 总结（需用户配置 API key）

### 不包含
- 子任务 / 子时间线
- 双向关联的可视化呈现（字段预留，UI 后期做）
- 云端同步
- 多用户
- 提醒通知

---

|------|------|
