# Robinne v0.3.0

这是一次面向发布链路验证的小版本迭代，重点是把 macOS DMG 分发形态走通，同时带上最近已经完成的 Git 远端同步能力。

## 本次更新

- 新增通用 Git 远端快照同步，支持配置远端地址、分支和同步目录，并在应用内完成校验、推送与拉取。
- macOS 发布产物新增 `.dmg` 安装盘，可直接拖拽 `Robinne.app` 到 `Applications` 安装。
- Release 附件会继续提供 `.zip`、`.dmg` 和 `SHA256SUMS.txt`，便于校验下载内容。

## 验证重点

- 下载 `Robinne-v0.3.0-macos.dmg` 后，确认镜像内包含 `Robinne.app` 和 `Applications` 快捷方式。
- 将应用拖入 `Applications` 后可正常启动。
- 远端同步依赖本机已有的 Git CLI 与认证配置，本次版本不托管平台账号密码。

## 已知说明

- 当前 macOS / Windows 产物仍未签名，本次版本主要用于验证 DMG 构建与发布流程。
- macOS 首次打开未签名应用时，系统可能提示无法验证开发者，需要手动放行。
