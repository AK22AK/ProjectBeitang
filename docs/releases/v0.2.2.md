# Robinne v0.2.2

这是一次补丁版本更新，重点补齐了设置面板的第一期可用能力，并完善了快捷键录制与反馈体验。当前对外分发的 macOS 安装方式仍建议优先使用 ZIP 中的 `Robinne.app`。

## 本次更新

- 设置页补齐了第一期能力，新增通用设置、快捷键设置、数据与同步、关于信息等可用模块。
- 快捷键设置支持直接录制组合键，不再需要手动输入文本。
- 快捷键录制过程增加实时预览、成功反馈和失败重录，错误提示会保留到下一次输入或退出录制。
- 明确区分全局快捷键与应用内面板切换，避免面板切换误当作全局热键。
- 优化了 Git 远端同步区域的按钮布局，修复窄宽度下的溢出问题。

## 验证重点

- 在设置页中修改启动默认面板、快速输入默认模式、提醒开关后，配置应立即生效。
- 在快捷键设置中录制新的组合键，确认成功后立即生效；录制无效组合时，错误提示与重录流程正常。
- 下载 `Robinne-v0.2.2-macos.zip` 并解压，确认其中的 `Robinne.app` 可拖入 `Applications` 并正常启动。
- 如果使用 Git 远端同步，请确认本机已安装 Git CLI 且 SSH 或凭据助手配置可用。

## 已知说明

- 当前 macOS / Windows 产物仍未签名，正式对外分发前仍需补充 macOS codesign / notarization。
- 本次版本如需 macOS 安装，请优先使用 ZIP 中的 `Robinne.app`，不要使用 `.dmg` 安装盘。
- Git 远端同步仍依赖本机已有认证配置，应用本身不托管远端平台账号密码。
