# Robinne v0.2.1

这是一次补丁版本更新，包含最近已经完成的 Git 远端同步能力。macOS 的 DMG 产物在本次版本中仅用于验证构建链路，当前对外分发仍建议使用 ZIP 中的 `Robinne.app`。

## 本次更新

- 新增通用 Git 远端快照同步，支持配置远端地址、分支和同步目录，并在应用内完成校验、推送与拉取。
- macOS 发布附件提供 `.zip` 包，可将其中的 `Robinne.app` 拖入 `Applications` 使用。
- Release 附件会继续提供 `.zip`、`.dmg` 和 `SHA256SUMS.txt`，其中 `.dmg` 当前仅作为构建验证产物保留。

## 验证重点

- 下载 `Robinne-v0.2.1-macos.zip` 并解压，确认其中的 `Robinne.app` 可拖入 `Applications` 并正常启动。
- 远端同步依赖本机已有的 Git CLI 与认证配置，本次版本不托管平台账号密码。

## 已知说明

- 当前 macOS / Windows 产物仍未签名，正式对外分发前仍需补充 macOS codesign / notarization。
- 本次版本如需 macOS 安装，请优先使用 ZIP 中的 `Robinne.app`，不要使用 `.dmg` 安装盘。
